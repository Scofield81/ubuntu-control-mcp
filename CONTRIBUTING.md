# Hozzájárulás az Ubuntu Control MCP fejlesztéséhez

Jelenleg hibajelentéseket és funkciójavaslatokat várunk a GitHub Issues felületén. A licenc
(lásd [`LICENSE`](LICENSE)) nem engedélyezi a módosított változatok szabad terjesztését, ezért
kód-hozzájárulásokat és pull requesteket jelenleg nem fogadunk.

Ha hibát találtál, vagy ötleted van egy új tool-hoz/funkcióhoz, nyiss egy issue-t, és írd le:

- mit próbáltál csinálni (melyik tool, milyen paraméterekkel);
- mi történt, és mit vártál volna helyette;
- ha releváns: `UBUNTU_CONTROL_MODE`, Ubuntu/Debian verzió, hiba a `stderr`/audit naplóban.
